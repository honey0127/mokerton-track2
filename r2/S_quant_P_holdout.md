# 2차 라운드 트랙 P (INT8 방식 교체) holdout 결과 (2026-10-25, 공용 PC)

규칙: `DECISION_R2.md` 트랙 P. holdout INT8 mAP 가 현재 방식(`int8-mixed-percentile`)보다 **0.30점 이상** 높고,
M1 INT8 p50 이 현재 방식의 **1.05배 이하**이면 교체한다. 여러 개가 통과하면 holdout mAP 가 가장 높은 것, 0.10점 이내면 빠른 것.

**결론 (seed 0·1·2 평균, 정확도 조건): B 는 교체 없음. D 는 P1 박스 경로 FP32 (평균 +0.83, 세 seed 모두 +0.5 이상) 가 통과.
D 교체는 M1 속도 측정(1.05배 이하)이 남아 있다.**
seed 0 단일 실행만 보면 B 512장, D Entropy 도 통과처럼 보였지만, 보정 seed 만 바꿔도 mAP 가 B 0.45, D 1.64 움직여서
seed 평균으로 다시 판정했다. 자세한 내용은 아래 [seed 3회 평균 판정](#seed-3회-평균-판정) 절.

## 조건

- FP32 모델: 트랙 S 와 같은 `r2/pc5070/models/base_{B_1280x384,D_640x192}_op13_fp32.onnx` (공용 PC 에서 다시 export).
- 기준: 같은 PC 의 `int8-mixed-percentile` (`exclude_base_*.txt` 제외 노드, Percentile, 보정 train 256장 seed 0). B 96.70 / D 90.15.
- 후보는 기준에서 한 가지씩만 바꿨다.
  - P1: 제외 목록을 `head_nodes.py --box-fp32` 출력으로 교체 (48노드).
  - P2: `sensitivity.py` (holdout 16장, 모듈별 출력 SNR) 하위 k 모듈을 기준 제외 목록에 추가. k=2/4/8 → 제외 60/64(D 62)/70 노드.
  - P3: Percentile 99.99 / 99.9999, 보정 512 / 1024장, Entropy.
- 채점: holdout 500장, Moderate AP40, `kitti_eval.py` (official-port), 2스레드.
- 실행 스크립트 `r2/run_pc5070_P.sh`, 로그 `r2/pc5070_P_run.log` (1회차), `r2/pc5070_P2_run.log` (P2 재실행),
  원본 기록 `r2/pc5070/results.jsonl`, 상세 `r2/pc5070/ap40/`.
- 1회차에서 P2 가 `sensitivity.py` 의 임시 ONNX 파일을 연 채로 ORT 가 읽으려다 Windows errno 13 으로 실패했다.
  `session()` 에서 파일을 닫은 뒤 읽도록 고치고 P2 만 다시 돌렸다 (다른 결과는 건너뜀).

## 관찰

- B 와 D 의 최선이 다르다. Entropy 는 D 에서 최고(+0.72)지만 B 에서 최하(−0.65). 한 방식을 두 모델에 같이 쓸 수 없다.
- B 는 보정 512장으로 FP32 와의 차이가 0.02 만 남는다. 1024장은 512장보다 낮아 장수에 단조롭지 않다 → seed 확인 필요.
- D 의 개선은 주로 Pedestrian 에서 온다 (기준 86.43 → Entropy 88.58, P1 87.60). FP32 대비 남은 차이는 0.80.
- P2 는 두 모델 모두 효과가 없고, D 에서는 k 가 클수록 낮아졌다. 16장 SNR 로 고른 모듈이 AP 와 맞지 않는다.
  B 에서 고른 모듈 대부분이 head(`/model.20/cv2·cv3`)라 P1 과 겹친다. 또 P2 는 선택에 holdout 16장을 써서 평가가 완전히 독립이 아니다.
- 모두 1회 실행이다. seed 재현성은 아래 P4 절에서 확인한다.
- P3(Entropy·보정 장수)는 양자화 scale 만 바뀌어 그래프 구조가 기준과 같으므로 속도도 같을 것으로 예상하지만,
  P1 은 FP32 노드가 늘어 M1 측정이 꼭 필요하다.

## P4 (조합) · seed 재현성

`r2/run_pc5070_P4.sh`, 로그 `r2/pc5070_P4_run.log` (2026-10-25 19:30 ~ 19:59).

- P4 는 `DECISION_R2.md` 대로 각 모델의 P1~P3 holdout 상위 두 가지를 조합한다.
  - D: Entropy + 박스 경로 FP32.
  - B: 1·2위(512장, 1024장)는 같은 축이라 조합할 수 없어 1위 512장 + 공동 3위(P1 박스 FP32, P2 top4) 각각.
- seed: 보정 이미지 seed 1·2 로 B 512장, D Entropy 를 다시 만들고, 기준 INT8 도 seed 1 로 한 번 더 만들어 잡음 크기를 본다.

| 모델 | 설정 | seed 0 | seed 1 | seed 2 | 평균 |
|---|---|---|---|---|---|
| B | 기준 INT8 | 96.70 | 96.77 | — | 96.74 |

- **보정 seed 만 바꿔도 holdout mAP 가 B 에서 0.45, D 에서 1.64 움직인다.** 0.30점 기준과 비슷하거나 더 크다.
- D Entropy 의 +0.72 는 seed 0 에서만 나왔다. seed 1·2 에서는 기준 seed 1 보다 낮고, 평균은 기준과 같다(+0.02).
- B 512장도 평균으로는 기준보다 +0.15 로, 0.30 에 못 미친다.
- P1(박스 FP32)과 P4 는 seed 0 한 번뿐이다. 같은 seed 0 보정 이미지를 쓴 기준과의 짝 비교라 P3 보다는 덜 흔들릴 수 있지만 확인하지 않았다.

### 규칙대로 판정하면 (정확도만)

- B: 통과 P3_n512 97.15, P4_n512_box 97.22 → 0.10 이내라 빠른 쪽. 그래프가 기준과 같은 P3_n512 가 유력.
- D: 통과 P4_entropy_box 91.20 이 다른 통과 후보(P3_entropy 90.87, P1_box 90.71)보다 0.10 이상 높아 1순위.
- 다만 위 seed 결과로 보면 P3 의 이득은 보정 이미지 운에 가깝다. seed 0 단일 실행으로 채택하면 잘못 고를 위험이 있다.

## seed 3회 평균 판정

seed 잡음이 0.30 기준과 비슷해서, 후보와 기준을 모두 seed 0·1·2 로 만들고 평균으로 다시 판정했다
(`r2/run_pc5070_Pseed.sh`, 로그 `r2/pc5070_Pseed_run.log`, 2026-10-25 20:03 ~ 20:20).
"짝 차이"는 같은 seed 보정 이미지를 쓴 기준과의 차이다.

| 모델 | 설정 | seed 0 | seed 1 | seed 2 | **평균** | 평균 Δ | 짝 차이 (s0 / s1 / s2) | 0.30 조건 |
|---|---|---|---|---|---|---|---|---|
| B | 기준 INT8 | 96.70 | 96.77 | 96.66 | **96.71** | — | — | — |
| B | P3 보정 512장 | 97.15 | 96.82 | 96.70 | 96.89 | +0.18 | +0.45 / +0.05 / +0.04 | |
| B | P4 512장 + 박스 FP32 | 97.22 | 97.04 | 96.68 | 96.98 | +0.27 | +0.52 / +0.27 / +0.02 | |
| D | 기준 INT8 | 90.15 | 89.59 | 90.55 | **90.10** | — | — | — |
| D | **P1 박스 경로 FP32** | 90.71 | 91.02 | 91.06 | **90.93** | **+0.83** | +0.56 / +1.43 / +0.51 | 통과 |
| D | P3 Entropy | 90.87 | 89.23 | 89.56 | 89.89 | −0.21 | +0.72 / −0.36 / −0.99 | |
| D | P4 Entropy + 박스 FP32 | 91.20 | 90.84 | 90.61 | 90.88 | +0.78 | +1.05 / +1.25 / +0.06 | 통과 |

- **B: 평균으로는 0.30 을 넘는 후보가 없다 → 현재 방식 유지.** P4_n512_box 가 +0.27 로 가장 가깝지만 seed 2 에서는 차이가 없다.
- **D: P1 박스 경로 FP32 가 세 seed 모두 기준보다 0.5점 이상 높다 (평균 +0.83).** P4(+Entropy)는 평균이 0.05 낮고
  seed 2 에서 이득이 사라지며, Entropy 단독은 오히려 손해다. 0.10 이내로 붙으므로 규칙상 빠른 쪽을 고르는데,
  P4 는 P1 과 그래프가 같고 scale 만 다르므로 속도가 같을 것으로 보고 더 단순하고 안정적인 **P1** 을 후보로 한다.
- D 의 P1 이득은 대부분 Pedestrian 에서 온다 (기준 평균 87.00 → P1 평균 87.91).
- seed 0 단일 판정(위 절)과 결론이 바뀐다: B 의 512장, D 의 Entropy 는 seed 0 운이었다.
